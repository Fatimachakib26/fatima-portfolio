# Past Tense Coach

Plateforme d'anglais A1–A2 (le passé), faite à partir du livre « Past Tense Made Easy ».

## Ouvrir sur ton ordinateur

**Méthode simple :** double-clique sur `index.html`. La page s'ouvre dans ton navigateur.

**Méthode localhost :** dans ce dossier, lance :

```bash
python3 -m http.server 8000
```

Puis ouvre http://localhost:8000 dans ton navigateur.

Pour qu'une autre personne sur **le même Wi-Fi** l'ouvre, donne-lui l'adresse de ton ordinateur :
`http://<adresse-IP-de-ton-ordinateur>:8000` (par exemple http://192.168.1.20:8000).

## À savoir

- Les leçons, les cartes de verbes, l'écoute, l'oral et les exercices marchent partout.
- Le prof IA (Teacher Nora) et la correction du journal marchent seulement dans la version ouverte dans Claude.
- La voix utilise le navigateur. Chrome et Edge marchent le mieux.
- La progression est enregistrée dans le navigateur de chaque personne.
